# NicaExport

## Descripción del proyecto

NicaExport es un proyecto universitario basado en el análisis de operaciones de exportación de NicaExport Trading, S.A. durante el año 2026.

En este trabajo se analizan las operaciones internacionales de la empresa, sus principales mercados, productos, rentabilidad y operaciones pendientes.

## Objetivo

Analizar el desempeño de las operaciones de exportación para identificar los mercados, productos y operaciones más rentables, y establecer prioridades para la toma de decisiones gerenciales.

## ¿Qué contiene el trabajo?

El proyecto contiene información y análisis sobre:

- Operaciones internacionales de NicaExport Trading, S.A.
- Valor FOB y utilidad de las operaciones.
- Operaciones pendientes.
- Principales mercados de exportación.
- Productos con mayor generación de utilidad.
- Operaciones prioritarias.
- Principales hallazgos.
- Conclusiones y recomendaciones.

En total se analizaron 100 operaciones, con un valor FOB total de US$658,265 y una utilidad total de US$214,072.
